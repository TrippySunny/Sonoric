Build 1.0.0

Player capabilities

Sonoric reads local audio files, visualizes them with shaders in real time, and keeps the library in sync across devices.

What this build can do

Custom mood tags

Your own mood categories instead of someone else’s genres. Filter the archive by tag combinations on tracks, folders, and artists.

Library sync

Sync the collection, custom tags, and settings between computers and mobile devices on the local network.

Playlists

Export and import collections in a lightweight .sonoric container, with no third-party cloud lock-in.

Library

Four sections: all songs, albums and playlists, artist pages, and folders of albums and playlists. Favorites is a filter, not a separate section.

Formats and requirements

Supported audio formats and system requirements for Sonoric 1.0.0
Item Value Notes
MP3 Supported Common lossy format
FLAC Supported Lossless compression
WAV Supported Uncompressed PCM
OGG Supported Vorbis and related containers
M4A Supported AAC in an MPEG-4 container
Operating systems Windows 10+, Linux x64 / arm64 Built with .NET 9 / Avalonia
Dependencies libvlc / VLC on Linux Windows builds ship the libraries
Graphics GPU with shader support Required for the audio-reactive visualizer
Network Not required for playback Only needed to sync devices
